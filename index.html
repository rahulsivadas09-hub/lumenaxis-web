Quick Setup Guide

Follow these steps to get your device ready before messaging us.

🔥 Firestick & Android

Option 1: STB Emu Pro

  1. Install the "Downloader" app.
  2. Enter code 381535 to install STB Emu.
  3. Open App > Settings > Profiles > STB Configuration.
  4. Find your MAC Address and send it to us.

Option 2: TiviMate

  1. Install the "Downloader" app.
  2. Enter code 272483 to install TiviMate.
  3. Message us to get your Username & Password.

📺 Samsung & LG Smart TV

Option 1: IBO Player

  1. Open your TV's App Store.
  2. Search for and install IBO Player Pro.
  3. Open the app and note down your Device ID and Device Key.
  4. Send both codes to us to activate.
